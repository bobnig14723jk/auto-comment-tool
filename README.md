# 自动评论发布工具

一款基于坐标模拟点击的自动评论发布工具，支持自定义话术、定时发送、随机间隔防风控。

## 功能特性

- ✅ **话术自定义** — 支持多条话术，按顺序循环发送
- ✅ **定时发送** — 可设定精确开始时间
- ✅ **坐标模拟点击** — 拾取评论输入框和发送按钮坐标，自动操作
- ✅ **持续循环运行** — 一直发直到手动停止或到时间
- ✅ **指定次数** — 发 N 轮自动停止
- ✅ **运行时长** — 设定运行时间，到点自动停止
- ✅ **随机发送间隔** — 可自定义最小~最大秒数，防风控
- ✅ **随机点击延迟** — 每次点击前随机等待，模拟人手操作
- ✅ **鼠标归位** — 每次操作后鼠标自动回到原位
- ✅ **紧急停止** — 鼠标移到屏幕左上角立即安全停止

## 快速开始

### 方式一：直接使用 exe（推荐）

直接下载 `自动评论发布工具.exe`，双击运行即可，无需安装 Python。

### 方式二：源码运行

```bash
pip install -r requirements.txt
python main.py
```

## 使用教程

### 第一步：填写话术

在"话术设置"区域输入评论内容，**每行一条**。

- 回车换行添加下一条
- 左上角实时显示话术总数
- 程序会按顺序循环发送

### 第二步：拾取坐标

点击"拾取坐标"按钮，3 秒倒计时内把鼠标移到目标位置，自动捕捉坐标。

需要拾取两个坐标：
1. **评论输入框坐标** — 评论/留言输入的位置
2. **发送按钮坐标** — 发送/提交按钮的位置

> 💡 建议先点击"测试点击"验证坐标是否正确

### 第三步：设置发送时间

- **留空** = 点击开始后立即执行
- **填入时间** = 到设定时间自动开始执行

快捷按钮：立即 / 1分钟后 / 5分钟后 / 10分钟后 / 30分钟后

### 第四步：防风控设置（可选）

| 设置 | 说明 |
|------|------|
| 随机发送间隔 | 勾选后启用，每轮间隔在设定范围内随机 |
| 点击延迟随机 | 每次点击前随机等待，模拟人手点击节奏 |

推荐设置：
- 发送间隔：20~50 秒随机
- 点击延迟：0.2~0.5 秒随机

### 第五步：运行模式

| 模式 | 说明 |
|------|------|
| 持续循环 | 一直发，点停止才停 |
| 指定次数 | 发 N 轮自动停止 |
| 运行时长 | 配合上面两种，到时间自动停止（填 0 = 不限时） |

### 第六步：开始执行

点击"开始执行"按钮，程序开始运行。运行状态区域会实时显示日志。

## 安全机制

- **紧急停止**：运行中把鼠标快速移到屏幕最左上角（0,0位置），立即停止所有操作
- **鼠标归位**：每次点击操作后鼠标自动回到原位置
- **失败容错**：单条发送失败不影响后续，日志会显示错误原因

## 注意事项

1. 使用前请先测试坐标是否正确
2. 运行时请确保目标窗口在前台且可见
3. 不要遮挡坐标位置
4. 合理设置间隔和延迟，避免过于频繁触发风控
5. 请遵守平台规则，合理使用
