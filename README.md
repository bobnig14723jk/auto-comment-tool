# 自动评论发布工具

基于坐标模拟点击的自动评论工具，支持自定义话术、定时发送、随机间隔防风控。**下载 exe 双击直接运行，无需安装任何东西。**

## 下载使用

直接下载右侧 **Releases** 里的 `自动评论发布工具.exe`，双击打开即用。

## 功能特点

- 话术自定义，多条循环发送
- 定时发送，精确到秒
- 坐标拾取，模拟点击
- 持续循环 / 指定次数 / 定时长 三种模式
- 随机发送间隔，防风控
- 随机点击延迟，模拟人手
- 紧急停止（鼠标移到屏幕左上角）

## 使用步骤

1. **填话术** — 话术设置区输入，每行一条
2. **拾坐标** — 点"拾取坐标"，3秒内把鼠标移到目标位置（输入框和发送按钮各一次）
3. **设时间** — 留空立即执行，或填指定时间
4. **开跑** — 点"开始执行"

## 安全提示

运行中想紧急停止，把鼠标快速移到屏幕**最左上角**即可自动停止。
